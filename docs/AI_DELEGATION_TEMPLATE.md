# 单任务委派与验收模板

本模板是现有工作项的子包，不另设主要活动目标，不复制状态文件历史。替换尖括号后使用；缺少必要字段时先补契约。

## 发给实施者

```text
主工作项：<work_item_id>
子包：<stable_id>；风险：<L0/L1/L2>；交付：<调查/补丁/本地实现>
目标：<一句可观察行为>
当前行为与证据：<路径、符号、复现输入、实际结果>
预期行为：<成功路径、失败路径、保持的边界>
范围外：<相邻功能、未接受的设计>
基线：<commit>；工作区已有改动：<清单或none>
读取文件与SHA256：<明确列表，附必要片段>
允许修改：<明确列表>；只读参考：<明确列表>
约束：10Hz世界权威、统一命令、合法知识、整卡、值拷贝、存档失败保原档。
验收：
1. <输入/动作 → 预期结果；含至少一个相关边界>
验证命令：<命令、环境、预期结束标记、日志路径>
无需运行的检查：<理由；不得省掉主工作流必需门>
调用策略：本次一个结果；信息不足一次列出缺口；不得递归委派或自行扩范围。
禁止：修改黄金/删除断言掩盖问题、读取或回显密钥、擅自提交/推送/联网。
能力说明：<本地代理可运行的工具，或外部文本模型无执行环境>
请只返回下面的交付字段；没有实际运行的验证标NOT_RUN。
```

L0文案包可以省掉无关代码片段，但保留来源与预期文本。纯外部文本模型不需要假称已读取本地AGENTS.md：主代理必须提供适用约束和必要上下文。

## 实施者返回

```text
子包ID / 基线：
结果：<交付待审 / 缺信息 / 失败>
实际改变及原因：<简短说明>
修改文件 / diff：<补丁或本地路径，不附无关整文件>
验收逐项：<PASS / FAIL / NOT_RUN + 证据>
执行命令：<原命令、退出码、结束标记、日志路径>
受验文件哈希 / 环境：
未完成及风险：
调用记录：<模型、attempt、usage、耗时；未知写UNKNOWN>
```

## 主代理验收记录

```text
子包ID：
范围与基线检查：<PASS/FAIL，说明>
diff审查：<核心结论；高风险完整行为链>
证据复用：<原日志、命令、哈希；为什么有效>
本地新增验证：<仅补缺口，不重复已有效验证>
决定：<ACCEPT / REWORK / ESCALATE>
返工项：<具体失败输入、预期、允许改动>
工作项状态与下一动作：<由主代理更新正常状态入口>
```

收到文本不是ACCEPT，ACCEPT子包也不等于主工作项DONE。任务包含多个子包时，最终集成与完整门在合并后的工作区一次执行；同一父工作项内部的验证不替代阶段依赖。
