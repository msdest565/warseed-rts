## 实现契约（2026-09-07）

- `BattlefieldSituationProjector` 只接受与请求阵营一致、非 true-state 且带知识网格的 `WorldSnapshot`；拒绝原因保持可测试。
- `BattlefieldSituationSnapshot` 是与来源快照解耦的值拷贝，固定输出战线段、卡牌任务轴、威胁区、未知/过期区域、卡牌状态和补给态势，并提供规范 JSON 与 fingerprint。
- 已知敌军接触与未被取代的情报报告按稳定 ID 聚合；可见接触标为确认，失去视野后仅使用最后已知位置、年龄和衰减置信度。
- `committed Supply` 统计已经支付但仍在部署中的部队卡，以及按 typed support cost 计算的 active/recovering 支援承诺；可用量仍直接取自权威快照，恢复来源和剩余时间分别具名列出。
- UI 只消费派生 DTO，通过独立叠层开关控制战线、任务、威胁和情报，不向模拟层写回任何状态。

## 实现结果（2026-09-07）

- 新增 `BattlefieldSituationProjector` 与深值拷贝 `BattlefieldSituationSnapshot`，稳定生成战线、任务轴、已知/最后已知威胁、探索不确定区、整卡任务状态和补给态势。
- 新增战场与小地图同步叠层；战线、任务、威胁、情报四层可用鼠标和 `Alt+1` 至 `Alt+4` 独立切换，整卡选中状态在两处同步高亮。
- 资源栏显示 available、committed、capacity Supply，以及部署和支援的具名恢复来源与时间。
- 投影器拒绝 true-state 和错误阵营快照；隐藏敌军真值变化不会污染玩家叠层。
