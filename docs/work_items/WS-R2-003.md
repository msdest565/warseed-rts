## 冻结说明（2026-09-07）

- R2 只实现一个受限的“目标 + 主攻轴 + 风险 + 预备队”意图模板，目的是验证交互闭环，而不是提前完成通用规划器。
- 异常是需要玩家注意的决策入口，不是高频通知流；稳定去重、自动解决和严重度阈值属于完成条件。
- 推荐处置不是唯一最优答案。所有会改变战场的处置仍由玩家确认，并沿现有权威命令管线执行。

## 完成记录（2026-09-07）

- 玩家现在可在紧凑指挥台选择负责将领、目标区、主攻轴、风险姿态和预备队政策；提交、替换和取消均通过 `CommanderOrderCommand`、`CommandValidator` 与 `SimulationWorld` 的统一权威管线。
- 已接受意图使用稳定 intent ID 写入将领权威状态和深值拷贝快照，并通过结构化任务事件、HUD 摘要及试玩观测回执保持一致；取消意图会终止开放任务并释放参与卡牌。
- `CommandSituationProjector` 只接受同阵营、同 source tick 的合法态势快照，确定性派生受阻、暴露、低组织、低 Supply 和增援请求五类异常；稳定 ID、排序、去重、解决与重开均由 focused suite 覆盖。
- 异常操作包含聚焦、重试任务、取消任务、脱离、请求增援、保持计划和确认；所有战场变更继续走既有任务、支援或将领命令管线，UI 不能直接修改模拟。
- 完整对局报告新增首条意图与异常开启、解决、重开和玩家处置指标。3 敌方计划 x 5 策略 x 2 重复确定性通过，aggregate fingerprint 为 `4d8204397a86e63d408e8c56cfd1866c2d7c1f60434c5b0e2adec293c433aa32`；15/15 仍为失败，未在本项调整平衡。
- 五档真实窗口矩阵通过，包含鼠标提交意图、权威快照确认和异常队列状态；最窄目标视口为 480x800。
