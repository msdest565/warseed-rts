## 调查结论

- `CommandSituationProjector` 过去为任何低组织或暴露卡无条件生成 `DISENGAGE_COMMANDER`，没有先验证关联将领是否存在、同阵营且仍控制该卡，导致界面可能提供必然拒绝的动作。
- 原回执虽显示通用校验结果，但没有显示命令对象；`INVALID_TARGET` 的恢复建议仍是选择地图目标，无法解释将领或控制权问题。
- 显式编队攻击会传播给全部成员，但自动接敌只在至少一个成员已进入武器射程后启动；将领协同又只从已经受击或已在射程内的卡开始，造成前排单元先打、同将领其他卡旁观。
- 原教程主要以已接受 UI 动作记录推进，缺少对整卡实际移动、自动交战和异常处置权威结果的确认，也没有持续显示失败恢复提示。

## 实现结果

- 决策区现在先按权威快照和当前控制权投影动作：Agent 控制卡提供“将领脱离接触”，玩家接管卡提供“归还将领”，没有合法负责将领时只提供聚焦，不再构造必然失败的撤离命令。
- 动作回执保留受影响将领或部队卡、接受/拒绝原因及恢复建议；同一异常在回执有效期内不会重复提交。撤离继续通过统一命令、校验和事件管线执行。
- 玩家阵营的 Agent 战斗卡可在 420 世界单位内发现合法可见威胁；同一将领附近、已部署且可用的战斗卡会共同响应，整卡所有可攻击成员获得协调目标并自动开火。
- 玩家接管、侦察任务、撤离姿态和撤退阶段均保持更高优先级；敌方仍沿用原有射程与兵力阈值，没有因本维护项获得额外索敌距离。
- 编队移动与攻击移动不再依赖固定领队存活；领队或部分成员阵亡时，剩余整卡仍可接收命令，只有整卡全灭才返回 `ENTITY_DISABLED`。
- 教程步骤改由 `WorldSnapshot` 中的部署、控制权、将领目标、侦察和路线状态确认；拒绝命令会显示原因与恢复方式。新增常驻 `?` 指挥指南，并补齐中英文的整卡协同、自动接敌、决策区和两类撤离说明。
