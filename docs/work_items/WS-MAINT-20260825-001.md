## 范围

- 战后结算增加可关闭、可重开的中英文反馈表单；
- 收集 1-5 分评价、优先完善板块、最佳部分、最大问题、具体建议和错误描述；
- 自动附带构建 ID、匿名会话 ID、关卡、战果、语言、分辨率和局数；
- 先写本地待发送 JSON，再通过 HTTP 提交；失败保留并允许重试，成功保留本地已发送副本；
- 提供本机/局域网反馈服务、健康检查、HTML 汇总、JSON 汇总和 CSV 导出；
- 将服务、配置、说明和最新版 Windows 导出放入冻结试玩包。

## 范围外

- 不收集姓名、账号、联系方式、IP 到反馈正文或战斗原始日志；
- 不把自填问卷或自动化结果升级为 `HUMAN` 验收证据；
- 不改变战斗权威状态、经济、地图、卡牌内容或 R1/R2 阶段门；
- 不提供公网托管、身份系统、访问控制或长期生产数据库。

## 行为契约

1. 合法反馈必须先原子写入本地 `pending`，网络请求不得先于本地持久化；
2. 仅 HTTP 2xx 且本地 `sent` 副本写入成功后，才删除对应 `pending`；
3. 服务端按 `feedback_id` 幂等，限制请求体为 256 KiB，并原子写 JSON；
4. 未配置或不可达的服务器不得阻止退出、重开或返回作战区；
5. `-Lan` 是显式开放动作；默认仅监听 `127.0.0.1`；
6. 汇总页面展示待完善板块票数和最近问题，CSV 保留原始文字供产品审查。
