# WARSEED 可玩版 2026-09-14

运行 `WARSEED.exe`，选择会战、编成部队并开始。无需安装 Godot 或配置反馈服务；保留同目录的 `WARSEED.pck`。存档保存在 Windows 用户目录，游戏包不包含开发测试存档。

- 右键移动；Q 后点击地面为攻击移动，点击可见敌人为指定攻击。
- 手控部队会向射程内可见敌人开火，普通移动继续执行。R 将当前部队交还 AI。
- 空格为战术暂停；暂停中可安排命令，恢复后执行。
- 左侧支援区顶部常驻显示当前补给 / 上限，消费和恢复后实时刷新，滚动支援列表不会隐藏数值。
- 发现敌方指挥所后，决策区出现作战将领进攻其已确认所在地的入口。
- 专业火力仍遵守弹药、识别、最小射程与准备条件；基本手控移动/进攻不再被旧 AI 任务或低组织锁住。

单位数量超过 56 时的消失问题已修复：批量显示使用实时插值坐标，且位于地形上方。攻击移动会接敌、追近，并在目标失效后继续原方向；混成卡攻击不会丢下非战斗成员。

坦克减速的现有规则：装甲在废墟中为基础速度的 70%，开阔地为 110%；快速机动结束后恢复正常地形速度。编队成员与队形位置差距超过 120 世界单位时，队形中心暂以 25% 速度等待成员，成员仍按自身速度追赶。这是整卡队形保持，不是压制不断叠加移速惩罚；本包已验证重复刷新不会叠加降速。

这是当前维护可玩包，包含已接入的将领阶段任务图，不代表 R4/R5 阶段已完成。完整发布脚本、两轮18套回归、四关矩阵、30场确定性对局和中英五档UI已通过；工程验证为 SIMULATED，真人体验研究仍为可选未运行。按用户要求，交付此包后暂停开发。

本包按产品负责人授权暂时放宽帧数要求；当前笔记本上的80单位实测帧耗时P95约16.8ms，尚未达到原16.667ms门槛。保留该测量，不将其描述为稳定60fps保证。
