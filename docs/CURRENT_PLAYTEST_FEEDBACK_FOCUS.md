# WARSEED 当前试玩反馈重点

适用构建：0.1.0-r1-feedback.2

目的：帮助试玩员把意见落到可开发的问题上，不用于暗示“正确答案”或代替观察员记录。

## 2026-09-01 首关修复专项

本候选版优先复测以下问题：

- “试玩验证目标”能否让首次玩家判断命令接受、实际执行和结算是否符合预期；
- 编成页悬停后，玩家能否区分固有性格、执行姿态和战法，并说出隐蔽搜索的收益与代价；
- 灰脊是否已移除无效的旧 RTS 全面接管入口，玩家能否通过拖将领卡和整卡区域命令完成调度；
- 8 至 12 单位预备卡在总部附近展开后，是否仍有 `E1100+` 动态单位卡在建筑或原地。

出现单位滞留时，请在反馈中填写关卡、部队卡、实体编号、部署方式、目标位置和大致发生时间，并附截图或录屏时间码。

## 当前可体验基线

| 板块 | 当前已有 | 目前尤其需要回答的问题 |
|---|---|---|
| 兵种 | 侦察、突击、导弹、工程、运输 5 类有效战术类型 | 哪些战场任务缺少可用兵种；现有类型是否真的有不同定位 |
| 地图 | 4 场会战；3 张 6144×4096、1 张 7168×4608 | 地图是太空、太挤还是缺少地标；路线与战线是否容易辨认 |
| 经济 | 会战内补给、区域控制、支援和增援 | 资源来源、消耗和决策代价是否清楚；等待是否过多 |
| 卡牌 | 12 张部队卡、12 张战法、12 项成长 | 卡牌和地图实体关系是否清楚；选择是否形成不同打法而非只换数字 |
| 任务与胜负 | 类型化目标、胜利/失败/有序撤离结算 | 玩家能否在行动前说清目标、失败条件和剩余时间 |
| 将领 Agent | 5 名将领，支持委托、接管、归还和行为理由 | Agent 是否可预测、是否抢权、玩家何时愿意委托或接管 |
| 战役与剧情 | 四场独立会战及军团战损/成长连续性 | 目前尚无正式战役行动图；玩家想看到怎样的选择、后果和剧情节奏 |
| 操作与界面 | 中英文、整卡控制、战前编成、战后成长、五档响应布局 | 哪个入口最难找；文字、焦点、滚动和鼠标/触控板操作哪里造成负担 |
| 节奏与平衡 | 当前正式规模 60-80 活跃实体；四关有难度与敌方计划 | 哪段无事可做、信息过载或难度突变；输赢是否让人理解原因 |

## 建议反馈写法

优先写“发生了什么、当时想做什么、为什么受阻、希望怎样变化”。例如：

    在雾林第一个情报过期后，我仍以为目标位置有效；
    我想让整张侦察卡重新确认目标，但没有找到明显入口；
    建议在过期情报旁直接提供重新侦察动作。

只写“内容少”“不好玩”无法直接转成工作项。即使没有解决方案，也请保留发生关卡、时机和困惑原话。

## 当前尚不能由问卷证明的事项

- 陌生玩家是否真正理解卡牌、Agent、情报和胜负条件；
- 正式难度、胜率、重玩意愿和长时疲劳是否达标；
- 局域网、多设备、防火墙和断线恢复是否在真实场地可靠；
- 护送胜利与有序撤离是否能被未见过规则的玩家主动完成；
- 内容扩充优先级是否已成为产品决定。

这些仍需按 HUMAN_VALIDATION_TEST_PLAN.md 由真人执行。游戏内问卷提供产品线索和缺陷复现上下文，不自动升级证据等级。
