# WARSEED 四场会战试玩包使用说明

这是开发阶段的 Windows 试玩版本，包含以下四场会战：

- 《灰脊矿区》
- 《断桥回声》
- 《雾林输线》
- 《黑井反击》

## 1. 普通游玩怎样启动

如果你只是自己体验游戏，不需要提交匿名试玩记录，请直接运行：

```text
build\windows\warseed-debug.exe
```

这种启动方式不会询问 `Anonymous playtest session id`。

请勿单独移动 EXE。`warseed-debug.exe` 和同目录下的 `warseed-debug.pck` 必须放在一起。

## 2. `Anonymous playtest session id` 是什么

运行 `START_WARSEED_PLAYTEST.cmd` 时出现的：

```text
Anonymous playtest session id:
```

是“匿名试玩会话编号”，不是账号、密码或联网登录。

它只在本机用于：

- 将不同测试者的存档、战损成长和试玩记录分开；
- 避免后一名测试者覆盖前一名测试者的数据；
- 让观察员知道一份记录属于哪一次匿名测试。

程序不会要求真实姓名。原始战斗记录不会上传；只有玩家在战后主动填写并提交的问卷会发送到包内明确配置的临时反馈服务器。可以输入自己新建的简单编号，例如：

```text
player001
tester_a
laptop01
```

编号应使用英文字母、数字、下划线或短横线。每名新测试者使用一个没有用过的新编号。

`START_WARSEED_PLAYTEST.cmd` 是正式试玩评估入口。游戏退出后，如果本次完成了会战，它还会继续询问观察员评价。普通玩家不需要使用这个入口。

## 3. 继续同一个匿名会话

双击启动脚本默认要求新编号，防止意外覆盖记录。确实需要继续同一名测试者的进度时，在解压目录打开 PowerShell，并执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\start_isolated_playtest.ps1 `
  -ExecutablePath .\build\windows\warseed-debug.exe `
  -SessionId "player001" -Resume -Evaluate
```

把 `player001` 换成第一次使用的编号。

## 4. 基础操作

- 将领指挥：把军团卡牌板中的将领卡拖到地图目标区域。
- 部队卡控制：选择已部署的部队卡，再使用卡牌上的命令或路线按钮。
- 地图选择：左键选择，拖动左键进行框选，右键下达情境命令。
- 路线规划：左键添加或拖动航路点，按界面中的“执行”或 `Enter` 提交。
- 撤销路线点：`Backspace`。
- 取消当前临时操作或退出路线规划：`C`，也可点击界面上的取消按钮。
- 地图平移：`W/A/S/D` 或按住鼠标中键拖动。
- 地图缩放：鼠标位于地图区域时滚动滚轮；在侧栏滚动不会缩放地图。
- 暂停菜单：`Esc`。

不同会战会增加桥梁、情报时效、运输保护、撤出和多轴增援等规则。进入会战后，以屏幕侧栏中的当前操作指引为准。

## 5. 战后意见反馈

每场会战结束后，结算页提供“提供试玩反馈”。问卷会明确列出当前待完善方向：

- 兵种类型与战场定位；
- 地图大小、地形与导航；
- 经济、补给与增援；
- 部队卡、战法与成长；
- 目标、胜利条件、将领 Agent、战役剧情、操作、节奏与平衡。

反馈会先保存在当前电脑，再尝试发送。服务器未启动或网络中断时不会丢失，可稍后在同一页面点击“重试待发送反馈”。

在同一台电脑收集时，先双击 `START_WARSEED_FEEDBACK_SERVER.cmd`，再启动游戏。局域网多机收集、看板和 CSV 导出见 `FEEDBACK_SERVER_GUIDE.md`；各板块当前已有内容和建议提问见 `CURRENT_PLAYTEST_FEEDBACK_FOCUS.md`。

## 6. 存档与匿名记录位置

存档、原始战斗记录和反馈发送队列保存在当前 Windows 用户目录：

```text
%APPDATA%\Godot\app_userdata\WARSEED\
```

普通启动的存档位于该目录中。匿名试玩入口的数据位于：

```text
playtest_runs\<匿名编号>\
```

不同匿名编号之间不会读取或覆盖彼此的存档。

## 7. 常见问题

### 游戏提示缺少 PCK 或无法启动

重新完整解压 ZIP，不要只复制 EXE，也不要在压缩包预览窗口中直接运行。

### 输入匿名编号后提示已经存在数据

开始全新测试时换一个新编号；继续原来的测试时使用第 3 节的 `-Resume` 命令。

### 地图滚轮没有缩放

先把鼠标移动到中央地图区域。鼠标位于卡牌板、支援栏或其他滚动面板时，滚轮只用于滚动界面。

### 如何完全重新开始普通游戏

优先使用游戏内的重新开始或重新会战入口。匿名测试需要全新状态时，使用一个新的匿名编号即可，不需要删除其他测试者的数据。

## 8. 版本说明

这是尚在开发中的测试版本，不是最终发行版。当前包使用未签名的 Windows Debug 导出，首次运行时 Windows 可能显示安全提示。请只从项目维护者提供的原始 ZIP 获取程序，并可使用包外提供的 SHA-256 校验 ZIP 是否完整。
