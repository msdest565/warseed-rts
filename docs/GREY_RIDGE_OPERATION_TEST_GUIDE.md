# 《灰脊矿区》操作与开发自测指南

本文用于开发者确认当前切片是否可操作、命令是否进入权威模拟，以及卡牌与地图实体是否正确对应。陌生玩家盲测仍以 `PLAYTEST_PROTOCOL.md` 为准，不应把本文作为盲测提示词。

## 1. 当前运行逻辑

所有操作统一经过以下链路：

```text
军团板或地图输入
-> GameCommand
-> CommandValidator
-> CommandQueue
-> SimulationWorld 固定 tick
-> WorldSnapshot / SimulationEvent
-> 地图、军团板、情报与声音反馈
```

- 战前编成期间权威时间保持在 tick 0，调整将领、战法、姿态和首发卡不会让敌军提前行动。
- 点击“开始会战”后才开始八分钟计时；敌方计划已在开局前锁定，不读取玩家选择后临时换答案。
- 正式控制下限是一整张部队卡。点击地图上的任一友军实体，会选中它所属部队卡的完整编队。
- 将领命令改变其全部已部署部曲的目标；部队卡接管只改变该卡的控制权。
- 支援、预备队部署和命令拒绝都通过同一个验证器，不会绕过补给、隶属、视野或部署时间规则。

## 2. 最短可玩闭环

### 战前

1. 在全屏编成板检查三名将领的指挥容量、战法和姿态；较窄分辨率下使用面板内部滚动查看全部部队卡。
2. 保持默认首发也可以直接测试；“首发 2 张部队卡”且容量没有红色错误时，“开始会战”可用。
3. 点击“开始会战”。预期：编成板收起，中央显示完整地图，左右和底部面板不覆盖地图。

### 将领级命令

1. 在右侧军团板按住“涤天”将领卡并拖到中央中继站，松开左键。
2. 预期：中央地图出现目标预览；松开后收到接受音，军团板中的行动、ETA、风险和退出条件发生变化。
3. 用同样方式把“白久漾”拖到西部矿场。
4. 预期：两名将领保持独立目标，所属部队由 Agent 自行行军和接敌。

### 支援与预备队

1. 在左侧“战区支援”选择“西部矿场 + 中央中继站”，点击“空中侦察”。
2. 预期：扣除 2 补给，情报区随后出现合法侦察报告；未知东部不会直接泄露真实敌军位置。
3. 点击右侧处于“总部预备”的部队卡，再在中央地图合法位置左键部署；也可以把预备卡拖到它当前隶属的将领卡上快速投入。
4. 预期：命令接受后进入 10 秒部署倒计时并扣除补给；拖给错误将领时拒绝且不扣补给。

### 部队卡级直接控制

1. 点击一张已部署部队卡，再点击“接管整队”。
2. 预期：整张卡所属的所有真实单位同时高亮，控制状态变为玩家接管；Agent 不再覆盖该卡命令。
3. 点击“路线 / 阵线”。在地图上用左键依次添加最多 8 个路径点。
4. 在最终位置按住右键拖出部署阵线并松开。预期：路线与阵线提交，整支编队沿路线移动并展开。
5. 点击“归还将领”。预期：部队先执行归队过程，完成后恢复 Agent 控制，不瞬移、不抢权。

### 地图与相机

- 鼠标位于中央地图内时滚轮：以指针位置缩放。位于军团板或其他面板时，滚轮只滚动对应界面，不改变地图比例尺。
- 鼠标中键拖动或 `W/A/S/D`：平移地图。
- 总览状态显示整张战区；放大后会显示单位编号与名称。
- 友军为青绿色，敌军为红色；侦察、突击和远程火力具有不同车体细节。选中单位显示黄色圆环。
- 地图外的面板和空白区不会接收战场点击。

## 3. 建议的单局检查顺序

1. 30 秒内完成一次将领拖拽命令。
2. 根据第一条新情报使用一次空中侦察或改变一名将领目标。
3. 投入一张总部预备卡，核对补给和 10 秒倒计时。
4. 接管一张完整部队卡，提交一条路线和阵线，再明确归还。
5. 把至少一名将领推进敌方总部，完成胜负结算。
6. 战后确认四张持续部队卡都有战损/成长行，点击“再次作战”应返回战前编成且计时重置为 08:00。

## 6. 新作战体系检查

- 将领级路线：在军团卡牌板点击“规划进攻路线”，在地图上左键添加最多 8 个航路点，右键指定最终目标。再次点击已变为“取消路线规划”的同一按钮，或按 `C`，会丢弃未提交航路点并保留当前生效命令。`Esc` 仅用于打开暂停菜单。
- 持续侦察：观察侦察群是否以宽扇形散开，进入指定区域中心附近后报告自身传感范围内的新接触，遭遇武装威胁时整队撤离，再选择新前沿继续搜索。同一接触持续可见时不会刷屏，脱离并重新发现后会再次告警。
- 共享响应：不再给编队追加玩家命令时，闲置的敌我作战编队都应基于各自合法视野自主接敌；已有将领任务的我方部队继续服从玩家规划。
- 战斗反馈：每次射击应能看到枪口闪光和弹道曳光；命中时目标闪光并出现冲击圈；摧毁时出现更大的短时爆炸。所有特效只消费快照，不改变伤害与确定性模拟。
- 屏幕适配：全屏编成板和战斗 HUD 会按分辨率重排。已检查 1366x768 与 480x800；中央地图保持独立且不被面板覆盖，总览单位保持可辨识轮廓。

需要退出后立即填写观察结果时增加 `-Evaluate`。完整的匿名化、记录和判定规则见 `PLAYTEST_PROTOCOL.md`。
