# WARSEED 玩法优先改写路线图

> 路线版本：1.0
> 生效日期：2026-09-07
> 决策依据：D-026、D-027
> 实时任务状态：[`AI_DEVELOPMENT_STATE.md`](AI_DEVELOPMENT_STATE.md)
> 工作流：[`AI_DEVELOPMENT_WORKFLOW.md`](AI_DEVELOPMENT_WORKFLOW.md)

## 1. 路线结论

保留 10 Hz 权威模拟、统一命令管线、公平阵营知识、整卡控制、稳定 ID、值拷贝快照和安全存档迁移。停止横向增加关卡与同质卡牌，先把《灰脊矿区》改造成能够证明核心乐趣的纵向基准。

R2-R7 的优先顺序改为：

```text
可观察的完整决策循环
 -> 有真实战术动词的卡牌
 -> 能提出方案并执行意图的我方 AI
 -> 有阶段、预备队和欺骗的敌方 AI
 -> 行动层与跨会战后果
 -> 内容生产和最终表现
```

旧 [`EXPANSION_IMPLEMENTATION_ROADMAP.md`](EXPANSION_IMPLEMENTATION_ROADMAP.md) 继续提供地图、混成卡、存档、补给与战役模块的技术参考，但其中原 R2-R7 顺序不再决定任务领取。

## 2. 验证政策

- 阶段出口依赖工程证据、完整对局代理、确定性、公平知识、性能、UI 实渲、存档和产品负责人审查。
- 真人试玩、访谈和问卷属于可选产品研究，不是工程、阶段或发布硬门。
- `HUMAN`、`SIMULATED` 和 `NOT_RUN` 只说明证据来源，不代表层级高低，也不得互相改写。
- 自动化不能证明主观乐趣；没有真人数据时，只能报告可操作性、决策差异、代理行为和因果解释等代理指标。
- 完整对局指标不得被开局 200 tick 窗口替代；短窗口测试只承担回归定位。

## 3. 产品行为目标

一场标准会战必须形成以下循环：

```text
读取任务、地形和不完整情报
 -> 选择目标、主攻轴、风险、补给和预备队
 -> 参谋提出 2-3 个有代价的行动方案
 -> 玩家批准或修改方案
 -> 将领按阶段化任务图执行
 -> 玩家只处理异常并在关键局部接管整卡
 -> 将部队明确归还将领
 -> 结算解释关键转折、卡牌贡献和失败原因
```

卡牌不以数量形成差异，而以新的行动、信息、编制、约束和反制形成差异。上层 AI 不使用 LLM 参与权威决策；建议结构为阵营知识黑板、行动方案生成与效用比较、将领任务图和部队行为树。

## 4. 阶段计划

| 阶段 | 核心问题 | 阶段出口 |
|---|---|---|
| R2 灰脊乐趣基准 | 玩家现在该决定什么、为何失败 | 灰脊具备完整对局观测、战线/威胁提示、异常驱动指挥和因果复盘；至少两种完整策略可被机器区分 |
| R3 卡牌战术语法 | 每张卡实际带来什么新动作 | 类型化效果、混成编制和首批 4-6 张差异化卡形成部署、战斗、接管、战损与存档闭环 |
| R4 我方分层 AI | 意图怎样变成可信计划 | 参谋生成 2-3 个方案；将领按阶段、预备队、撤退和重规划规则执行；代理纠正负担达到门槛 |
| R5 敌方行动 AI | 敌人怎样公平而不机械 | Doctrine + Operation Plan + Reaction Rules + Reserve Policy 数据化；多轴、牵制和撤退可复盘且无隐藏信息读取 |
| R6 第一章行动层 | 会战选择怎样产生跨局后果 | 行动图、补给承诺、持续损失和四关后果闭环；正式地图/补给所需技术从旧路线按需迁入 |
| R7 内容与表现 | 系统怎样稳定生产更多内容 | 内容验证器、第二章样板、正式资产、可访问性、性能和存档完整门通过 |

## 6. 暂不实施

- 国家级外交、科技、生产和领土沙盘；
- 新增更多同质关卡、同质部队卡和纯倍率成长；
- 单兵级正式操作；
- 在 `SimulationWorld` 继续添加关卡或 doctrine ID 特判；
- 依赖网络或 LLM 的权威战斗、寻路、决策和内容加载；
- 在核心循环达到阶段门前追求最终美术覆盖。

## 7. 代理指标

以下指标用于没有真人门时的工程决策，不得描述为主观乐趣证明：

- 首条有效高层意图可以在进入战场后 30 秒等价 tick 窗口内生成；
- 每场形成 3-5 次中等资源承诺或一次重投入加 2-3 次支援；
- 至少两种兵力与路线不同的策略能跨三个敌方计划完成灰脊；
- 委托 Agent 的完整对局中，每 10 分钟强制纠正不超过 2 次；
- 每个受阻、撤退、增援、改令和结算都具有权威 reason、来源事件和时间；
- 决策矩阵同时包含成功、失败、恢复、无干预和知识公平案例；
- 80 活跃实体继续满足正式性能门，120 实体只作压力测量。
