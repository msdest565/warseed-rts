# WARSEED 产品愿景

> 本文服从 [整合版游戏企划书](GAME_DESIGN_DOCUMENT.md) 与决策 D-017。

## 一句话定义

《WARSEED》是一款用常驻军团卡牌组织真实战场编队，并让玩家在将领 Agent 指挥与部队卡级直接操作之间切换的即时战术游戏。

## 玩家幻想

玩家是最高指挥官。战前将持续存在的部队卡挂到具名将领下，为其装配有限战法；战中把将领拖向战区、设定姿态和目标，观察其组织下属行军、展开、接敌和撤退。关键局部出现时，玩家可以选中一张部队卡，为整个编队绘制路线和阵线，完成后再明确归还将领。

> 你决定把谁交给谁、在哪里打、怎样打；将领把意图变成可信的战场行动，部队则把卡面上的编制真实展开。

## 核心体验支柱

### 1. 卡牌就是军队

将领卡、部队卡、战法卡、荣誉与装备卡全部可见且持续存在，不抽牌、不洗牌。部队卡对应一组真实战场实体，其现员、战损、经历、装备和隶属关系跨战斗保存。

卡牌的作用不是提供一次性技能，而是同时承担：

- 战前军团编成；
- 将领与部曲的组织关系；
- Agent 如何理解命令的战法配置；
- 战中整队选择和直接控制入口；
- 战后损失、荣誉和故事的持续载体。

### 2. Agent 真正执行意图

将领必须把“守住中央”“从西侧牵制”“谨慎搜索东部”等意图转化为地图上真实发生的行军、展开、观察、交战和脱离。Agent 与玩家使用相同的合法命令、视野、资源和战斗规则，不能直接修改战果。

### 3. 指挥粒度可切换

- 将领级：拖动将领卡到战区，由其组织全部部曲；
- 调整级：修改目标、姿态、路线偏好、撤退阈值和增援；
- 部队卡级：选中完整编队，直接绘制路线和展开阵线。

正式玩法不逐个士兵或单车微操。玩家直接命令始终优先，但 Agent 只有在玩家明确归还后才能重新接管。

### 4. 情报有来源、有时间、有可信度

未侦察区域不能视为安全。每条报告应说明观测来源、发生时间、估计数量、移动方向和可信度。主 AI 可以汇总矛盾并指出风险，但不提供伪装成唯一答案的“最优推荐”。

### 5. 敌方计划公平且可复盘

场景加载时即锁定敌方初始编成、计划模板、反应条件、延迟和撤退阈值。敌人可以按照已定义规则响应其确实观察到的行动，但不能在读取玩家选择后临时生成针对答案。

## 核心会战循环

```text
阅读任务和地形
  -> 编成军团并装配战法
  -> 部署首发与侦察
  -> 争夺自动产出的资源区
  -> 接收带可信度的敌情
  -> 调整将领目标、姿态和增援
  -> Agent 自主展开与交战
  -> 必要时直接控制一张部队卡
  -> 摧毁总部或完成场景目标
  -> 战损、荣誉和经历回写
```

首要会战模式使用补给、人口和自动结算资源区，不要求矿车往返、逐车生产或复杂基地建设。现有基地 RTS 系统保留为技术资产和未来模式候选，但不再定义首个新 MVP。

## 指挥组织

### 玩家：最高指挥官

决定战略目标、主攻方向、风险、预备队投入、将领编成和控制权归属。

### 主 AI“枢机”：参谋长

汇总情报、距离、资源承诺和任务冲突，向玩家说明当前局势和缺口。枢机不替玩家选择唯一答案，也不直接控制底层实体。

### 将领 Agent

每张将领卡是独立指挥 Agent，拥有容量、性格、特长和战法槽。将领只管理组织树下的部队卡，根据阵营知识与玩家意图处理局部战斗。

### 部队 Agent

部队卡下属实体依据确定性规则完成槽位、掩护、射界、目标分配、近距自卫、脱困和伤员脱离，不调用语言模型。

## 首个样板局

《灰脊矿区》是一场八分钟会战：中央废墟即将接敌，西部有中可信度履带信号，东部完全未知。玩家只能在一个方向形成明显优势，需要用常驻军团板投入预备部队、改变将领目标并在必要时直接控制完整编队。

该切片验证的不是内容数量，而是以下闭环是否成立：

**卡牌编成 -> 战场展开 -> Agent 执行 -> 情报改变判断 -> 部队卡级接管 -> 明确归还 -> 战损回写**

## 产品原则

1. 卡牌必须改变组织、行为或持续状态，不能只是按钮皮肤。
2. Agent 处理执行，玩家保留方向、风险、时机和资源投入。
3. 玩家与 Agent 使用同一命令边界和阵营知识。
4. 失败必须能解释，受阻必须有具体原因。
5. 正式操作下限是部队卡，个体选择仅用于开发诊断。
6. MVP 在完全离线、不启用语言模型时必须可玩。
7. 先验证《灰脊矿区》，再扩充基地经营、战役和更多内容。

## MVP 非目标

- 随机抽牌、牌库构筑、卡包或稀有度商业系统；
- 单兵选择和高频逐单位微操；
- 完整基地建设、矿车经济和复杂科技树；
- 多人 PvP、完整战役和多阵营内容；
- 每个实体使用语言模型；
- 自然语言作为唯一命令入口；
- 最终品质美术、音频和叙事。

## 长期方向

核心切片成立后，再探索跨会战军团成长、更多将领关系、丰富战法、战役资源、不同敌方计划模板、自然语言命令和更大规模战场。任何扩展都不能破坏卡牌与真实实体的一致性、玩家最终控制权和公平信息边界。
