# P6.7 陌生玩家验收 cohort 计划

> 冻结日期：2026-08-18
> 候选范围：WARSEED 四场会战 P6.7 候选版
> 执行协议：`PLAYTEST_PROTOCOL.md`
> 当前政策：D-026 后为可选产品研究，不参与工程、阶段或发布门

## 1. 目的与边界

本计划在收集真人数据前冻结样本分组和通过阈值，防止根据结果临时改变标准。它验证新玩家能否理解常驻军团卡牌、将领 Agent、情报、整卡控制和四关递进规则，不用于估计商业留存、长期平衡或统计显著性。

自动化、自主试玩、开发者、看过源码/企划/操作视频的人，以及旁观过其他测试场次的人都不能计入陌生玩家样本。胜负不是理解门槛；完成失败结算的会战仍是有效记录。

## 2. 样本与分组

最低招募 9 名互相独立的陌生玩家，使用匿名 ID `p67-01` 至 `p67-09`。所有人先完成《灰脊矿区》；后续覆盖按下表预注册：

| 匿名 ID | 必测会战 | 目的 |
|---|---|---|
| p67-01—p67-03 | 灰脊、断桥、雾林、黑井，按顺序 | 验证完整教程迁移、共享战损和成长连续性 |
| p67-04—p67-05 | 灰脊、断桥 | 增加工程路线和高地火力样本 |
| p67-06—p67-07 | 灰脊、雾林 | 增加情报时效、运输保护和补给节点样本 |
| p67-08—p67-09 | 灰脊、黑井 | 增加十二卡、组织恢复和多轴增援样本 |

最终最低覆盖为：灰脊 9 份，断桥/雾林/黑井各 5 份，其中 3 名玩家提供完整四关连续记录。玩家可分多次坐席完成，但必须复用同一匿名 ID 和 `-Resume`，不能重置失败或战损后重新计数。

## 3. 环境覆盖

- 至少 3 人使用 1280×720 或更小的笔记本显示区域；
- 至少 2 人使用触控板，至少 4 人使用鼠标；同一人可同时计入鼠标和低分辨率覆盖；
- 全部使用键盘与指针输入，不启用 `F3`，除非玩家自行发现并主动尝试；
- 至少 7 人使用中文界面；英文界面样本可计入总人数，但不能替代中文最低数；
- 观察员不得在首条有效命令或 30 秒前提供操作提示，也不得推荐 A/B/C、路线或主攻方向。

## 4. 预注册通过阈值

《灰脊矿区》首次接触样本必须同时满足：

- 至少 8/9 人完成战前编成并完成一次胜利或失败结算；
- 至少 8/9 人在 30 秒内下达第一条有效将领或部队卡命令；
- 至少 8/9 人正确解释部队卡与地图实体的对应关系；
- 至少 7/9 人正确解释一名将领的行动原因；
- 至少 7/9 人正确解释一次敌方反应来自锁定计划或合法情报；
- 至少 7/9 人在新情报后采取一次有效行动；
- 至少 7/9 人完成一次整卡接管和明确归还；
- 至少 8/9 人不依赖单体诊断模式完成核心操作；
- 至少 6/9 人明确愿意尝试另一种编成、战法、路线或主攻方向。

后续会战必须同时满足：

- 断桥、雾林、黑井各至少 4/5 份记录完成结算；
- 每关至少 4/5 人能说明该关新增规则如何改变决策；
- 三名完整串联玩家均生成四关记录，共享 roster 的 `battle_count` 最终为 4，黑井能读取此前战损、组织和成长；
- 不得出现因教程遮挡地图、入口不可见、无法取消目标模式、无法提交合法命令或存档污染导致的未完成记录。

若实际组织该研究，任一 P0 崩溃、存档破坏或无法继续流程应停止当前研究构建并建立工程缺陷；P1/P2 作为产品输入分流。是否追加新陌生玩家复测由产品负责人决定，不影响已经独立满足的工程状态。

## 5. 数据完整性

每个有效会战必须同时存在：

- 原始 `latest_<scenario>.json` 或对应归档记录；
- 独立 `_assessment.json`，四项观察结论均附玩家原话或行为证据；
- 匿名会话 ID、会战 ID、敌方计划、结果、开始时间和局号；
- 分辨率、输入设备、语言和观察员 ID 的场次登记。

原始记录不得被人工编辑。重复评估只保留时间较新的报告，但旧文件仍保留审计；队列汇总必须显示四关覆盖数，不能只报告总通过率。

## 6. 放行判定

只有在样本覆盖、全部阈值和缺陷闭环同时满足后，P6.7 才可标记完成。`all_sessions_pass`、自动化全绿、开发者自测或不足 9 名玩家均不能单独触发放行。若招募或环境覆盖不足，状态保持“候选版，人工证据不完整”。
